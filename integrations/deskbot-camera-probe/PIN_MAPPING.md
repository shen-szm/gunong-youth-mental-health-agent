## 固件改写结果

`src/main.cpp` 已移除原来的裸 GPIO 常量，改用 `src/camera_pins_from_schematic.h`。头文件由工程数据生成，每行注释记录模组脚 → FPC 焊盘 → 网络 → U4 端子 → GPIO。启动串口增加 `[PINMAP]` 输出。

数据口按 Y2..Y9 对应 pin_d0..pin_d7：`39,18,8,17,38,47,21,13`；SDA=9，SCL=10，XCLK=14，PCLK=48，VSYNC=11，HREF=12。RESET 与 PWDN 无 U4 GPIO 连接，依据原理图分别由 R6 上拉、R8 下拉，所以配置为 -1。

独立推导出的数值与原诊断固件一致。此次是依据硬件记录重写配置来源，未产生不同的 GPIO 电气行为，也不能声称摄像头已经修复。此次修改对象是本目录的摄像头独立诊断固件，未改写供应商仅提供二进制的固件。

## 如果实物是同号相接

如果模组脚 n 实际连接 FPC1 的 n 号焊盘，按同一份 PCB 网络记录会出现以下连接：

| 模组功能 | 同号连接落点 | 结果 |
| --- | --- | --- |
| PCLK（17） | FPC1.17 / $1N79 | 下拉电路，无 MCU GPIO |
| DVDD（10） | FPC1.10 / GND | 电源脚落到地 |
| DGND（15） | FPC1.15 / VCC_1V2 | 地脚落到电源 |
| Y3（21） | FPC1.21 / VCC_2V8 | 数据脚落到电源 |
| Y8（14） | FPC1.14 / VCC_2V8 | 数据脚落到电源 |

因此同号假设不能生成完整有效的固件引脚配置；改变 GPIO 数字不能改变这些焊接网络。没有生成或烧录这种配置。

## 实物验证与型号边界

断电并断开 USB、电池后，核实模组 AGND（2）与板端 FPC1.23、模组 DGND（15）与 FPC1.10 的接触对应；信号也应检查模组 SDA（3）至 FPC1.22。测点必须按接触面与焊盘标号识别，不能凭照片左右计数；不要刺破排线。

此前诊断日志识别 PID=0x3660；本次用户提供的模组图为 OV2640。两图信号名称的脚位相同，不代表电源规格相同。OV3660 图的 DVDD 标称 1.5 V，而本地板图为 VCC_1V2。这仍需实测与实际模组规格核对，未由引脚重写解决。

电压测量只在焊盘编号已确认后进行：板端黑表笔接已确认的 GND，红表笔测 FPC1.21（图纸 2.8 V）、15（图纸 1.2 V）、14（图纸 2.8 V）。以上是图纸标称值，不是本次实测结果。
