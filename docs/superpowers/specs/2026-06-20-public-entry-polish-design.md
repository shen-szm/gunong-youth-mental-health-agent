# 公开入口与首页信息展示优化设计

## 目标

优化公开展示体验：备案号在房间页明显可读，HTTP 与 HTTPS 普通访问都不出现登录界面，并从首页移除小掌机游戏窗口。

## 设计

- 备案信息改为高对比浮条：深色半透明背景、白色文字、加粗、阴影与边框，保证在像素背景上清晰可读。
- 普通访问不展示登录页：
  - `/`、HTTP 或 HTTPS 的普通访问继续自动绑定演示用户进入主界面。
  - `/login` 不再显示登录界面，直接重定向到 `/`。
  - 教师登录保留为隐藏路径 `/teacher-login`。
- 移除小掌机：
  - 首页小工具栏只保留小空调和小电视。
  - 删除 `ikk` 配置和小掌机专用遮罩。

## 兼容性

- 教师端 `/admin`、`is_admin`、演示用户自动进入逻辑保持不变。
- 旧 `/login` 链接不会暴露登录页，只会进入首页。
- 教师需要使用 `/teacher-login` 登录。

## 验证

- 回归测试确认 `/login` 重定向 `/`，`/teacher-login` 渲染登录页。
- 回归测试确认 `App.vue` 对 `/teacher-login` 使用登录页全屏样式。
- 回归测试确认首页源码不再包含小掌机、`ikk`、`giao.me/ikk`。
- 回归测试确认备案样式包含高对比背景、白色文字、阴影与加粗。
- 前端生产构建通过。
