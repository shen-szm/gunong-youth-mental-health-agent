# 教师端可见文案改造设计

## 目标

将产品中面向使用者展示的“管理员/管理后台”统一调整为“教师/教师端”，使该入口符合校园心理健康场景中的教师角色定位。

## 范围

本次只修改用户可见文案，不迁移内部权限模型或接口：

- 页面角色徽标由“管理员”改为“教师”。
- 入口名称和页面标题由“管理后台”改为“教师端”。
- 用户角色展示由“管理员”改为“教师”。
- 角色设置操作由“设管理/取消管理”改为“设为教师/取消教师”。
- 登录及接口错误提示中的“管理员权限/账号”改为“教师权限/账号”。
- 密码找回提示中的“联系管理员”改为“联系教师”。
- AI 心理分析提示中的“给管理者的建议”改为“给教师的建议”。

## 兼容性约束

以下内部实现保持不变：

- 数据库字段 `is_admin`。
- 前端状态字段 `isAdmin`。
- 前端路由 `/admin` 与组件文件 `AdminView.vue`。
- 后端路由前缀 `/api/admin`。
- 默认账号用户名 `admin` 及现有账号数据。
- 函数、CSS 类名、日志标识等内部技术命名。

这样可以避免数据库迁移、线上账号失效、接口变更和部署兼容问题。

## 交互与视觉

不改变现有布局、颜色、组件、交互流程和权限能力。教师登录后仍直接进入原管理页面，可查看用户数据、情绪趋势、AI 分析与对话记录，并执行现有用户管理操作。

## 验证

- 全量搜索前后端用户可见字符串，确认不存在遗漏的“管理员/管理后台”文案。
- 运行前端生产构建，确认 Vue 模板和脚本编译通过。
- 运行 Python 语法编译检查，确认后端文案修改未引入语法错误。
- 核对内部字段、路由和 API 路径未发生变化。
