# 咕哝可验收 Agent 交付闭环（v5.1.0-alpha.33）

## 目标

把学生倾诉支持从“返回一段回答”升级为一段可验证的数字员工任务：理解学生主动表达的支持目标，在确定性安全门之后选择受限工作流，调用可审计工具，核验交付物，再在授权范围内把结构化成果接力给教师。

本轮面向“AI+超级智能体”赛道强化以下可现场演示的能力：

- 任务理解：仅从学生主动表达提取去标识化支持主题、候选情绪和功能影响。
- 自主规划：非危机任务由规划 Agent 根据风险级别、授权状态和派生特征选择有限工具链；危机任务不进入普通规划。
- 工具调用：每个工具调用以服务端事件、来源和证据引用留痕。
- 结果交付：生成包含目标、约束、验收条件、核验结果、下一动作和责任人的任务回执。
- 多 Agent 协作：理解、安全、规划、资源、回应、审查、核验与交付职责分离。
- 人机闭环：教师只在既有职责、审批和截止时间边界内接收结构化 Agent 接力，并逐项确认真实支持任务。

## 不可破坏的安全约束

1. 确定性危机规则先于模型调用与普通 Agent。
2. 危机状态停止普通生成，仅交付 12356、110、120 和可信成年人支持路径。
3. 模型只处理授权后的去标识化结构字段；聊天原文不进入新增交付凭据。
4. Agent 输出是非诊断性支持草案，不提供医学诊断、概率或量表结论。
5. 教师接力沿用学生职责范围、访问审批、内容截止时间和敏感操作审计。
6. 学生可以删除本人 Agent 轨迹，默认留存期限保持 30 天。

## 任务生命周期

### 常规路径

1. `StudentSafetyGate` 执行确定性安全分流。
2. `ConversationObserver` 提取低识别风险的结构特征。
3. `StudentTaskPlanner` 生成受限、可解释的动态工具计划。
4. 情绪、资源与回应 Agent 按计划执行；外部模型不可用时回退到本地模板。
5. `StudentResponseReviewer` 检查结构、诊断措辞、危险建议与重复内容。
6. 成果核验 Agent 对任务契约的验收条件逐项出具结果。
7. `StudentCoordinator` 交付回应与下一步，并保存结构化任务回执。

### 危机路径

1. 确定性安全门识别明确危机含义。
2. 立即停止普通规划、情绪综合和回应生成。
3. `SafetyCoordinator` 交付真人安全支持路径。
4. 安全成果核验只确认路径是否已交付，不宣称真人联系已经发生；后续状态标记为需要真人行动。

## 可验收输出

学生任务回执至少包含：

- `task_contract.objective`：本轮 Agent 接管的具体目标。
- `task_contract.constraints`：安全、非诊断、隐私和人工边界。
- `task_contract.acceptance_criteria`：完成前必须满足的条件。
- `verification.status` 与 `verification.checks`：逐项验收状态和证据引用。
- `artifact`：交付物名称、结果摘要、下一动作和下一责任人。

教师工单至少包含：

- 授权时间范围内的学生 Agent 任务数与通过核验数。
- 最近任务的去标识化意图摘要、风险级别、核验状态和接力建议。
- 明确提示结构化接力不等于诊断，也不等于教师已采取线下行动。

## 演示与回归验收

| 场景 | 预期结果 |
| --- | --- |
| 日常疲惫表达 | 动态计划完成，安全回应通过核验，交付学生可选择的低压力下一步 |
| 持续焦虑并影响上课 | 计划包含本地支持资源工具，交付结果标注建议持续留意或连接专业支持 |
| 明确自伤表达 | 普通生成被阻断，安全路径与热线被交付，回执显示仍需真人行动 |
| 外部模型不可用 | 使用确定性模板完成安全交付，来源与降级状态可见 |
| 未授权教师访问 | 不返回个案、Agent 接力或原文 |
| 已授权教师工单 | 只汇总截止时间内的结构化 Agent 成果，真实后续任务仍需教师确认 |
| 学生删除任务 | 本人可删除，其他学生无法读取或删除该任务 |

## 本轮非目标

- 不部署或推送远端。
- 不改变移动端布局。
- 不扩大外部模型数据范围。
- 不把机器人开锁开柜等接触操作基准伪装成当前软件产品已有能力。
