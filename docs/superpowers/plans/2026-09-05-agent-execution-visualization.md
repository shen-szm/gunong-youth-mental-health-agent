实现依据 [Vue Flow 入门](https://vueflow.dev/guide/getting-started.html) 与 [自定义节点](https://vueflow.dev/guide/node.html) 文档；没有从头编写图渲染引擎。界面采用 impeccable 的 product register，延续现有深暖色学生面板，使用状态文字、可聚焦按钮和克制的分区。

## 数据与交互

- 聊天响应追加已有数据库的 plan；与历史恢复 API 保持一致，无数据库迁移。
- 实际执行工具从事件读取，计划工具从 plan 读取。计划中的模型工具没有执行记录时，不算已调用。
- 图按计划顺序排列，连线表示该顺序，并不宣称多个角色是独立模型或并发进程。
- 当前系统在完成阶段保存部分事件，因此这是已保存轨迹的观察视图，不是逐工具实时流，也没有虚构步骤耗时。
- 手动拖动滑块可查看前 N 个事件；不会重放模型调用、自动执行任务或披露之后的事件结果。
- 无计划的历史记录保留查看能力，但不补造计划连线；计划外失败/恢复事件单独显示。
- 危机路径只展示实际返回的安全计划；核验通过并不代表真人已经行动。
- 图与“最近一次任务回执”分别标注；下方回执始终是最新交付成果，不随回看位置改写。
- 按需加载 Vue Flow，桌面手动开启图；移动端不挂载图组件。

## 验证

执行投影单测覆盖未来事件隐藏、模型降级、真人待处理、无计划历史、计划外失败事件；API 测试对比即时响应与恢复计划；浏览器回归覆盖节点查看、键盘回看、返回最新、移动端隐藏和危机路径。

本轮实测：后端 114 项、前端 107 项通过；开发模式与生产构建均通过完整浏览器回归，无页面运行时错误。生产构建成功，执行图独立 JS 包 gzip 约 53.9 KB。生产依赖 `npm audit --omit=dev` 报告 0 项漏洞；开发工具的既有报告与主包体积警告未在本轮扩展处理。Vue Flow 及其运行时依赖的完整许可证随站点 `third-party-agent.txt` 分发。

## 发布

用户已于本轮授权执行发布。通过本地测试、生产构建与预览后，本地提交，再备份线上代码与静态文件并切换。线上数据库和用户文件均保留；仅同步环境配置中公开的 RELEASE_VERSION 字段，其他字段、文件权限与所有者保持原值；以服务健康版本和静态资源可达性为验收依据。

第一次发布健康检查发现线上 .env 固定了 alpha.32 版本号，已自动回滚且确认旧版服务正常。发布脚本因此增加版本字段的原子更新、预期值检查和回滚恢复，不打印配置内容。
