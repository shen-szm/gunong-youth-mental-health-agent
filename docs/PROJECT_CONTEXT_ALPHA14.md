# 咕哝 5.1.0-alpha.14 项目上下文

## 1. 项目目标

面向“AI+超级智能体”赛道，把现有学生陪伴端、教师端与守护者端连接为：学生主动表达与互动 → 确定性安全分流 → 多 Agent 整理与复核 → 学生下一步 → 教师授权后工作成果。定位为心理健康教育、支持建议与求助导航，不诊断、不治疗。

## 2. 当前目录结构

- `frontend/`：Vue 3 + Vite；学生房间、倾诉、情绪回顾、心岛和教师工作台。
- `backend/`：FastAPI + SQLAlchemy；会话、Agent、安全策略、报告与审计。
- `backend/agents/`：心岛与学生支持需求多 Agent。
- `backend/tests/`、`frontend/tests/`：API、安全和界面契约测试。
- `docs/research/`：开源项目与实现调研。

## 3. 已完成功能

- 学生倾诉：讯飞逐会话同意、脱敏上下文、结构化情绪证据、结束确认、30天小结与危机覆盖。
- 支持需求自评：近两周四领域、明确安全项、六阶段 Agent、证据复核、冲突裁决、下一步和主动删除；全部标记待专业审核。
- 心岛：二维移动、自动昼夜、宠物照护、种植、钓鱼、呼吸、幸福交换与 Agent 侧栏。
- 教师端：普通教师申请并经管理员教师审批后查看原文；管理员教师可直接查看；授权成果包含自评观察与 Agent 轨迹。
- 安全：HttpOnly 会话、用户作用域、敏感访问审计、危机时停止普通 Agent/PDF、12356/110/120 路径。

## 4. 正在完善

- 将心岛、倾诉、自评的状态进一步统一为单一可审计运行图。
- 增加更完整的服务重启、并发幂等、留存清理与 PDF 视觉测试。
- 教师端报告继续加强“信息不足”和线下复核提示。

## 5. 关键技术

- 前端：Vue 3、Vite、Pinia、Phaser、Swiper、液态玻璃 + 暖色像素风。
- 后端：FastAPI、Pydantic 严格 Schema、SQLAlchemy、SSE、ReportLab、讯飞 Spark/ASR/TTS。
- 安全：确定性 SafetyGate 优先；模型只整理受约束文字；后置内容校验；不保存思维链。

## 6. 重要文件

- `backend/api/chat.py`：学生聊天、情绪识别、完整会话小结。
- `backend/api/assessment.py`：支持需求自评 API。
- `backend/agents/wellbeing_assessment.py`：六阶段自评 Agent 编排与复核。
- `backend/agents/orchestrator.py`：心岛 Agent 安全优先调度。
- `backend/api/teacher.py`：教师授权、预警和工作成果。
- `frontend/src/components/StudentWellbeingAssessment.vue`：学生自评交互与 Agent 裁决展示。
- `frontend/src/views/TrendView.vue`、`AdminView.vue`：学生回顾与教师工作台。

## 7. 已知问题

- 自评题目是自建支持需求观察，未做心理测量学验证，不能当作标准量表。
- 尚无持证心理专家签署；所有结果均为待专业人员审核。
- 心岛敏感运行表的全局定时清理、报告幂等与并发控制仍需继续完善。
- 部分旧代码仍使用无时区 `datetime.utcnow()`，测试会出现弃用警告。

## 8. 下一步

1. 做持证心理专家、未成年人保护与个人信息合规评审。
2. 补齐全局留存清理、报告幂等、服务重启和并发测试。
3. 用合成边界个案完成桌面端端到端演示和比赛讲解材料。
4. 仅在审核通过后考虑真实场景试点。

## 9. 约束

- 不部署、不推送、不操作线上数据；只在 `127.0.0.1` 预览。
- 不提交 `.env`、密钥、数据库、日志、生产备份或真实用户数据。
- 不使用游戏行为、点击速度或停留时间推断心理状态。
- 不展示思维链，不把 Agent 描述成真人专家会诊。
- 紧急安全规则始终覆盖模型与普通工作流。
