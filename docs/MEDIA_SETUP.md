# 可选媒体素材

公开仓库不附带来源或再分发权未核验的音乐、音效和视频。默认构建会隐藏依赖这些素材的播放入口，其余房间、城市探索和智能体功能不受影响。

如需在自己的部署中启用媒体能力：

1. 仅使用自制、公共领域或取得明确再分发授权的素材。
2. 将素材放入 `frontend/public/audio/` 与 `frontend/public/videos/`。
3. 在 `RoomHomeView.vue` 中配置播放清单，并将 `bundledMediaAvailable` 改为通过部署配置读取。
4. 在发布前更新 `ASSET_LICENSES.md`，写明每个文件的作者、来源、许可证和授权日期。

不要提交来源不明的网络下载素材，也不要使用可能侵犯角色著作权或商标权的形象。
