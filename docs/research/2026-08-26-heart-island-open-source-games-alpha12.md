# 心岛开源玩法落地记录（5.1.0-alpha.12）

## 选择结论

本轮不嵌入第三方网页、不复制第三方美术资源，而是在咕哝现有 Vue 3 + Vite 架构中选择性复用成熟的开源运行时或规则模型。以下 Star 数为 2026-08-26 调研时的约数，只用于说明社区认可度，不作为安全或质量保证。

| 项目 | 社区认可度 | 技术与功能 | 优点 | 局限 | 心岛采用方式 |
| --- | ---: | --- | --- | --- | --- |
| [Phaser](https://github.com/phaserjs/phaser) | 约 40.1k Stars | JavaScript/TypeScript、Canvas/WebGL、Scene、输入、计时、声音和物理 | 2D 游戏生态成熟，运行循环和输入系统完整 | 包体较大，必须懒加载并管理销毁生命周期 | 固定为 3.90.0，月光钓鱼湾使用真实 Scene、计时事件和逐帧收线状态；关闭心岛时销毁实例 |
| [2048](https://github.com/gabrielecirulli/2048) | 约 13.3k Stars | 原生 JavaScript、网格移动与合并 | 规则易懂、单局短、方向操作适合键盘 | 原作目标与青少年心理支持无关，原 UI 不适合直接搬用 | 仅在 MIT 许可下适配方向遍历和单次合并规则，重做为四乘四作物成长、撤销和收获 |
| [Swiper](https://github.com/nolimits4web/swiper) | 约 41.9k Stars | JavaScript/TypeScript、触控轮播、Cards 效果、键盘和 A11y 模块 | 滑动反馈成熟，桌面和触控交互一致 | 初始化于动态布局时需要显式约束尺寸和网格定位 | 固定为 12.2.0，承载幸福交换树的系统预写卡组；不接入用户间实时内容 |

## 未采用方案

- 未采用低关注度或 GPL/AGPL 的完整农场、钓鱼仓库，避免把未知依赖、遥测、服务端代码和许可证传染风险带入现有产品。
- 未复制 Phaser Examples 的美术、声音或其他资产；场景图形与交互文案均为项目内实现。
- 未使用排行榜、连续签到、失败惩罚或无限随机奖励，避免用压力和上瘾机制替代休闲陪伴价值。

## 产品与安全边界

- 心岛 Agent 只依据学生主动选择的地点、实际完成的交互和自愿回看反馈编排下一步，不以分数、点击速度或停留时间推断情绪。
- 幸福小事保存在当前浏览器按数字账号划分的空间，每条记录分别在创建 30 天后清理并允许主动删除；界面明确共享设备风险，不把本地命名空间描述成服务端访问控制。卡片明确为系统预写，不伪装成其他学生分享。
- 明确危机表达由确定性安全门优先接管，停止普通交换、不保存该段文字，并提供可信成年人、12356、110、120和正式倾诉入口。
- 右侧五步 Agent 轨迹仅显示可核验状态，不显示模型私有思维链，也不把休闲玩法描述成诊断或治疗。

## 验收证据

- 前端静态与契约测试覆盖规则合并、学生作用域、30 天到期、依赖版本、安全门和单一心岛入口。
- 浏览器端到端测试覆盖连续挂载/销毁、二维移动、玩法切换、真实钓鱼/种田/交换、危机阻断、键盘焦点和移动端回归。
