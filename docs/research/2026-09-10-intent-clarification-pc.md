# PC 需求澄清展示（本地候选）

采用 Impeccable 的产品交互原则，在既有教师端颜色和字体体系内增加页内澄清区，无额外弹窗或装饰性进度。

- 按固定白名单展示本地检查类别，不显示服务返回的任意未知字段。
- 首次命中的原文在组件内存中保留，编辑输入框不会覆盖它；不写入 localStorage 或 sessionStorage。
- 说明否定条件和引用也可能误触发，不引导删除真实约束。
- 后续解析即使返回合法合同，也不显示合同准备入口，并明确说明仍待澄清。
- 未将需求转交其他教师，未保存审核档案，未实现人工批准恢复。组件销毁后内存状态消失；这只是交互限制，不是后端授权机制，也不防止刷新、直接 API 或标准计划入口绕过本页状态。后端任务权限检查仍是执行边界。
