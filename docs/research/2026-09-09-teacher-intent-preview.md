# 教师自然语言需求预览

## 本轮能力

PC 个案准备区在未创建任务时提供一句话输入。教师确认仅发送任务要求后，调用既有配置的 Spark 通道解析结构化合同；不附带学生资料、账号编号或聊天记录。需求文本不写入本地存储或任务 checkpoint。服务商对请求的处理仍受其配置和政策约束，不能把“不写入本项目存档”解释为外部服务不保留数据。

候选合同展示目标、天数、成果和资源政策，教师核对后显式准备任务；复用现有 case-plans 接口的权限和合同限制。创建后仍需确认计划，再执行。现有标准任务按钮继续可用。

实现复用 TaskContract、Spark 客户端、全局外部模型开关及教师规划开关，不新增模型依赖。impeccable skill 用于输入、发送确认和合同核对的内联 PC 布局。

## 边界

- 当前可执行组合仍仅为个案沟通准备、30 天、报告与清单、不额外检索、待审核交付。其他有效合同显示不支持，不自动修改目标。
- 模型输出必须符合严格 JSON Schema 和枚举。要求澄清、无合同、异常 JSON、超时、模型关闭或不可用时不给予可准备状态，不使用规则识别假装模型理解成功。
- 格式校验不能证明语义理解正确。提示词约束模型不得忽略额外要求，但仍可能误解或受提示注入影响；人工核对和固定后端执行边界是必要约束，不能宣称已解决语义可靠性。
- 原始意图与解析来源尚未绑定持久任务；验收台仍只显示已保存合同及固定计划来源。跨刷新无法回放原始意图，不是完整规划审计。
- 不启用全局模型开关，不部署线上，不进行真实学生数据调用。角色受保护；文本最多 600 字符；用户明确确认才调用模型。

## 验证

新增测试覆盖确认前不调用模型、模型关闭、合法合同仅预览、非支持时间范围保留、未知/非法输出、受限错误返回及 API 的教师角色/长度/严格布尔校验。

PC 端到端用本地关闭模型的真实接口验证降级，再用明确的预览响应测试替身验证候选合同核对、编辑后作废和真实待确认任务创建，并回归修订、审签、历史及验收台。截图使用测试替身，不能作为真实模型质量证据。

下一阶段应以标注清晰的合成需求集测试真实模型的完整约束保留率、澄清正确率和拒绝不支持操作的表现，再决定是否启用试点。
