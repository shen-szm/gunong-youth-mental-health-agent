# 教师任务存档清理

本轮交付运维清理命令，默认预览，不安装定时任务、不操作线上库、不修改 PC 或移动界面。

## 使用

在仓库根目录使用已安装 Agent 依赖的 Python，显式指定既有任务运行目录：

```powershell
.\backend\venv\Scripts\python.exe backend/scripts/cleanup_teacher_tasks.py --directory backend/.teacher-plan-runtime
```

确认 JSON 中的过期任务范围，并按机构的数据保留要求完成备份/删除审批后，才使用实际清理参数：

```powershell
.\backend\venv\Scripts\python.exe backend/scripts/cleanup_teacher_tasks.py --directory backend/.teacher-plan-runtime --apply
```

`--apply` 删除任务 checkpoint、对应 `:case` 子流程、pending writes 与重试计数，不删除教师报告或业务数据库。删除无法通过本命令撤销，只能从事前备份恢复。预览不创建运行目录、数据库或表，不删除任务；运行中仍会短暂占用现有协调锁。

## 安全范围

- 与现有执行流程使用同一 SQLite 跨进程锁，避免同时执行/清理。检查和删除在持锁期间完成。
- 只处理规范 UUID 根任务，并且其最新存档具有有效教师标识和带时区的过期时间。无效元数据报告为待人工检查，实际清理全批次停止。
- 未过期任务保留。未过期任务引用的过期祖先递归保留，返回 `retained_dependency_ids` 供管理员检查。
- 保留过期祖先只是保留关联证据，不延长权限或有效期；既有访问接口仍按到期规则拒绝访问。处理这类依赖需要后续生命周期策略，不应直接强制删除。
- 所有候选任务的父/子存档及重试记录在单一事务内提交，任一删除失败均回滚。
- 仅打开明确目录下已有的 `coordination.sqlite` 与 `checkpoints.sqlite`；拒绝不完整目录及文件符号链接，不递归删除目录，不打印任务正文。

## 验收

隔离临时目录测试覆盖默认预览、删除过期任务与子流程、保留有效任务和报告文件、重复执行、有效任务的跨层祖先保留、异常元数据、缺失目录不创建、执行锁竞争及故障事务回滚。所有实际删除仅在这些临时测试数据中执行。
