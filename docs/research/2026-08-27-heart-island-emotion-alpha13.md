## 选型结论

- GitHub 上 JavaScript 钓鱼和农场成品仓库的高 Star 候选很少，常见项目只有个位数到几十 Star，且不少没有明确许可证。不能为了“使用开源”直接复制低质量或无授权代码。
- 本版采用高认可度 MIT 运行时 Phaser 与 Swiper，借鉴高 Star 完整游戏的玩法循环；地图、种植状态机、钓鱼规则、资源、文案和视觉均在本项目内实现。
- 旧 2048 种田从产品和运行路径中移除。新种田包含翻地、四类种子、浇水联动生长、收获篮、岛民订单、种子购买、岛币和咕团协助。
- 新钓鱼包含力度落点、咬钩反应窗口、不同鱼行为、张力控制、六类图鉴、精度记录与岛币奖励。

## 情绪识别闭环

1. 确定性安全门先检查自伤、自杀、已实施伤害、家庭伤害和功能严重受损。
2. 学生逐会话明确同意后，最近六轮文本在服务端脱敏，再提交给既有讯飞接口。
3. 模型只能返回固定 JSON：主要情绪、非临床强度、逐字证据、支持需要和短回复；额外字段、虚构证据、诊断、量表、概率与危险建议全部拒绝。
4. 学生消息保存通过校验的情绪标签；完成会话后生成主要/次要情绪、开始—中段—最近变化、证据充分度和下一步。
5. 心岛活动只使用学生结束后的主动自评，不根据输赢、点击速度或停留时长推断情绪。
6. “回顾情绪”统一汇总主动心情记录、活动后反馈、对话线索和最近倾诉小结，并显示数据来源与非诊断边界。
