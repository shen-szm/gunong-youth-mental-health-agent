# PC 教师审核工作区增量

范围：只优化 >=1024px 的桌面界面；保留原移动端布局和行为。不修改后端业务规则，不上线。

## 已实现

- 打开任务报告后，学生列表转为横向选择，释放工作区宽度。左侧保留任务范围、真实执行步骤、交付与刷新，右侧阅读和审核精确绑定的报告。
- 右侧提供报告概览、证据核对、审核签署三种视图。版本号、报告编号和审核状态随滚动保持可见；审签操作集中在表单底部。
- 切换视图不重新请求或生成报告，不重置填写中的审核意见和清单。继续复用既有报告组件和后端权限/版本校验。
- 退回后，左侧集中显示已保存的审核意见与报告原有信息缺口；这些是已有记录，不伪装为 Agent 新规划。自动补充任务尚未接入，界面明确说明，不提供无后台支持的执行按钮。
- 使用 impeccable skill 延续既有教师端色彩、控件与专业信息层级，采用桌面断点限定新布局。

## 验证

真实本地接口浏览器测试覆盖退回、旧任务不换版、新任务绑定修订版、证据视图、键盘切换、签署和刷新恢复。在 1280/1440/1920 宽度断言左右并排且页面无横向溢出。截图检查 1440px 审签工作区。

前端测试新增 PC 视图约束检查；构建通过。验收数据来自隔离合成账户，不代表真实教师使用成效。
