# 教师任务界面：真实执行与交付验收

日期：2026-09-08。状态：本地实现，未发布；生产默认关闭持久化执行试点。

## 本轮交付

教师端「支持工单」的已授权个案中加入独立任务面板，沿用 impeccable skill 的现有设计体系、明确状态与移动适配原则，没有另造一套装饰性 Agent 大屏。

流程：创建沟通准备计划 → 教师确认或取消 → 显式执行 → 四个服务端工具节点的完成状态 → 下载对应编号的待审核 PDF。

- 受限契约：个案沟通准备、近 30 天、授权范围、标准报告及核对清单；不能通过界面要求越权读取或额外检索。
- 初始四步显示「未执行」，只有真实响应中的 completed_tools 可以变为「已完成」。等待期间不添加假的逐步打勾或模型思维文字。
- 完成状态是「报告待审核」，并保留证据缺口提示、报告编号和 SHA-256；不是线下关怀完成，不表示效果验证。
- 刷新页面只读取状态，不自动发起 POST 或重试。浏览器只保存 requestId/taskId，按教师账户、学生和审批请求隔离，不保存姓名、原文、报告正文。
- 网络结果不确定时先禁用写操作，要求刷新状态；服务端失败可以显式断点恢复，最多三次。权限变化、校验冲突后撤下旧下载入口。
- 学生切换通过组件实例隔离；卸载后忽略晚到响应。取消计划后可以准备另一份计划，不隐式删除既有后台记录。
- GET /api/teacher/tasks/capabilities 仅教师可读；关闭试点或旧版本没有此接口时不显示入口。基础服务不需要导入可选 LangGraph 包。

## 验收方式与数据来源

数据来自隔离的合成测试账户，不是实际学生使用记录。报告通过现有真实业务接口生成；验收环境禁止外部模型调用，不用这次结果声称模型质量或真实心理改善效果。

本地启动（仓库根目录）：

```powershell
.\backend\venv\Scripts\python.exe backend/scripts/serve_teacher_task_preview.py
```

另一个终端进入 frontend：

```powershell
$env:VITE_API_TARGET='http://127.0.0.1:8018'
npm run dev -- --port 5179 --strictPort
```

在 frontend 运行浏览器验收：

```powershell
$env:RUN_TEACHER_TASK_E2E='1'
$env:TEACHER_TASK_SCREENSHOTS='1'
node --test tests/teacher-case-task.e2e.mjs
```

验收服务器只监听 127.0.0.1，使用临时磁盘 SQLite 支持并发页面请求，退出时清理；绝不能作为生产服务使用。测试凭据仅存在于隔离验收环境。

覆盖：真实登录、创建、人工确认、真实执行与 PDF 下载、刷新不重跑、取消、学生切换、仅编号存储、390px 页面无横向溢出、功能关闭隐藏入口。额外注入一次 503 和权限 403 验证前端失败处理；这些故障注入不是实际线上故障。后端另有真实职责撤销和报告篡改拒绝测试。

截至本轮：前端单元/静态测试 112 项通过，后端 153 项通过，真实接口浏览器端到端用例通过，Vite 构建通过。既有大包体积警告及 Python 弃用/测试连接资源警告仍存在，不把它们计为已修复。

## 后续增量：精确报告在线审签

教师现在可以直接打开任务绑定的报告，核对证据、填写意见、退回修订或签署；任务面板同步显示「待补充修订 / 教师已签署」。旧任务不会随 latest 报告变化而换版。审批范围、教师和学生身份继续由后端核对，详情、PDF 和草稿审核均增加内容哈希校验。

复用既有审核组件和决策表；任务内禁止脱离任务独立重新生成。移动端审核提供证据追溯区域，提交中冻结表单，签署/退回后保留终态。没有新增外部模型调用，也没有将审核意见放入 checkpoint 或浏览器存储。

增量验收：后端全量 154 项通过；前端 112 项通过；浏览器新增真实接口用例覆盖在线退回、生成新版后仍读取旧版、显式新任务绑定新版、手机端证据核对与签署、刷新后终态保留。与原有任务执行用例合计 2 项通过。构建仍有既有大包警告。
