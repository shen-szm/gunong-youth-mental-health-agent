# PC 任务历史与失败记录

## 本轮交付

沿用既有 LangGraph SQLite 存档实现历史查询，不引入第二套工作流引擎。教师在个案任务区显式打开历史，可找回当前学生、当前审批范围、本人创建且有效期内的最近 30 个任务。历史点击只读取，不确认或执行计划；报告仍通过原有精确版本和权限校验读取。

列表显示计划状态和存档更新时间，不将计划确认解释为报告交付。终止、取消和补充任务均可找回；过期或已删除记录不展示。列表只返回编号、计划状态、更新时间、到期时间及补充计划标记，不返回正文或失败原文。

失败记录持久化受限分类、时间、尝试次数。当前支持资料/产物校验冲突、工具执行失败两类；未知原因明确提示未记录，不猜测模型错误。显式重试成功后清除当前失败摘要，已有旧 checkpoint 仍按存档策略保留。这不是完整逐次失败日志，也不覆盖执行前鉴权拒绝、进程崩溃或所有 HTTP 错误。

使用 impeccable skill 保留教师端既有视觉语言，采用内联历史列表、独立空状态和北京时间显示；没有新增移动端布局。

## 安全与限制

- 查询前后检查个案权限，存档读取时再检查教师角色；匹配所有者和完整 target，不能跨教师、学生或审批范围枚举。
- 查询不删除过期记录，也不触发工具执行；角色失效时拒绝访问。
- 当前适用于本地磁盘小规模试点：按最新 checkpoint 遍历根任务再筛选，返回最多 30 条并提示截断，不提供翻页。大规模上线前需增加权限索引、游标分页和性能验证。
- 任务到期后沿既有清理策略处理；并非永久审计存储。没有修改生产数据库或开启默认关闭的试点开关。

## 验收

专项测试检查所有者/学生/审批范围隔离、最新状态去重、条数限制、过期过滤但不删除、停用角色拒绝、API 权限以及错误分类刷新后恢复、恢复成功后清除摘要。PC 浏览器回归原有修订审签流程，再验证找回终止任务、学生隔离和查看不触发新任务执行；截图用于实际检查布局。

所有测试使用隔离合成账号和临时数据库，不代表真实学生效果或线上运行成功率。

本地结果：后端全量 166 项通过，前端 114 项通过，PC 端到端回归通过；最终构建通过，仍存在既有大文件分包警告。实际截图检查后修正历史按钮样式，并重跑 PC 回归验证。
