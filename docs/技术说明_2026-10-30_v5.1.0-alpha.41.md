## 1. 项目定位与边界

咕哝·心岛是面向青少年（核心 12–18 岁）的心理健康教育、倾听、支持建议与求助导航 Web 应用，同时服务学生、教师与守护者（家长/监护人）。

产品边界：

- **不诊断、不治疗、不使用正式量表给出临床结论**。PHQ-9 筛查只作为可选的标准化筛查工具，用于支持分流，结果必须由专业人员进一步核实。
- AI 负责倾听、整理与可验收的支持建议，**不替代真人**。危机判断、风险等级、会话状态与安全交接由本地确定性规则裁决。
- 学生数据默认最小化：教师只能看到授权范围内的结构化结果，不能直接看到聊天原文；筛查只展示分级、总分、填写时间与第 9 题安全标记。
- 所有“下一步”都应落到学生可执行的行动或真人支持，不把需要真人介入的任务交给学生独自完成。

## 3. 系统架构

```text
┌─────────────────────────────────────────────────────────────┐
│ 浏览器（学生 / 教师 / 守护者）                                │
│ Vue 3 + Vite + Pinia + Vue Router                            │
│ 学生端：首页大厅 / 倾诉 / 回顾 / 我的 / 心岛 / 树洞 / 疗愈    │
│ 教师端：工作台 / 审批 / 预警 / 报告 / 验收台                  │
│ 守护端：接待 / 个案 / 回访                                    │
└───────────────────────────┬─────────────────────────────────┘
                            │ HTTPS / JSON，HttpOnly 会话 Cookie
┌───────────────────────────▼─────────────────────────────────┐
│ FastAPI 后端                                                  │
│ api/：chat、screening、assessment、mood、teacher、guardian…  │
│ 确定性安全层：危机词、safeguarding、风险分级、真人交接        │
│ 本地引擎：PHQ-9 计分、筛查风险、会话生命周期、审计             │
│ Agent 层：支持需求编排、任务契约、交付核验、教师任务           │
│ 外部模型：DeepSeek 小满（可选）/ 讯飞旧分支（回滚）            │
│ SQLAlchemy + SQLite（开发）/ MySQL（可选）                    │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 前端

- Vue 3 Composition API + Vite 5；`vue-router` 管理学生、教师、守护者路由；Pinia 管理用户状态。
- 学生子页共用 `.game-page` 昼夜皮肤；首页使用独立的 `.lobby-home` 主题大厅。
- 重资源按需加载：Phaser 钓鱼/心岛、Swiper、Vue Flow、音乐面板等不进入首屏主包。
- 图标使用 `@lucide/vue`；背景音乐使用 Howler.js 2.2.4。

### 3.2 后端

- FastAPI + Pydantic 2 + SQLAlchemy 2；开发默认 SQLite，生产可切换 MySQL。
- 路由模块：`chat`、`companion`、`screening`、`assessment`、`mood`、`music`、`teacher`、`guardian`、`island`、`student_agent`、`teacher_tasks` 等。
- 报告与 PDF 使用 ReportLab；外部模型使用 `httpx`。
- 会话鉴权使用 HttpOnly Cookie；教师/守护者接口有角色与授权校验；敏感访问写审计记录。

### 3.3 AI 与规则的分工

| 环节 | 由谁决定 | 说明 |
|---|---|---|
| 危机识别与风险等级 | 本地确定性规则 | 危机词、safeguarding、紧急程度；模型不可用时仍生效 |
| 本轮回应 | DeepSeek 小满（可选） | 只负责“像朋友一样说话”；失败时本地兜底 |
| 情绪标签/强度/会话状态 | 本地规则 + 受约束模型输出 | 模型输出经过校验；界面不展示分数、量表名或诊断词 |
| 倾诉后小结 | DeepSeek（有授权时） | 只采信能在学生原话中逐字找到的引用；异常整份回退模板 |
| PHQ-9 计分与分级 | 本地确定性计算 | 不发送外部模型 |
| 教师可见内容 | 后端授权与最小化投影 | 只给分级、总分、时间、第 9 题安全标记等 |

## 5. 学生端功能

### 5.1 首页大厅（`/`）

首页由 `RoomHomeView.vue` 承担，是学生端唯一主入口；`/room` 已重定向到 `/`。

- **欢迎遮罩**：会话内首次进入显示版本与“轻触，开始今天的倾诉”，点击任意位置进入；不阻断返回首页的再次访问。
- **问候与时间**：按小时显示“早上好/中午好/下午好/晚上好/夜深了”；右上角显示当前时间、天气、音乐开关与“我的”。
- **天气**：调用 Open-Meteo 当前天气接口；优先使用浏览器定位，拒绝授权时回退到广州坐标（23.13, 113.26）。天气失败显示 `--`，不影响页面。
- **主视觉**：咕团宠物舞台 + “今天想说什么？”标题 + 每日返回任务文案 + 超大“开始倾诉”CTA。
- **四张主卡**：回顾（`/trend`）、心岛（休闲中心）、咕团（宠物面板）、今天（签到与小心愿）。
- **次级入口**：“听点音乐”“看看窗外”。
- **摸咕团**：点击宠物触发爱心/星芒像素粒子和光环反馈；尊重 `prefers-reduced-motion`。
- **首次引导**：首次使用按“电脑 → 倾诉 → 心情卡”三步推进；引导徽标指向 CTA；可跳过。
- **底栏**：仅 `/chat`、`/trend`、`/profile` 显示共用底栏（首页/倾诉/回顾/我的/声音）；首页自带完整导航，不重复显示底栏。

### 5.2 昼夜与天象

- 时间分段：`06:00–16:59` 白天，`17:00–19:59` 傍晚，其余为夜晚。首页与子页使用同一分段口径。
- 主题：`day / evening / night` 三套 CSS token，分别控制底色、卡片、文字、金色强调、阴影和场景图。
- 场景：`lobby-scene-day.svg`、`lobby-scene-evening.svg`、`lobby-scene-night.svg`，均为 1600×1000、`shape-rendering="crispEdges"` 的像素风矢量图；SVG 内**不烘焙**太阳或月亮。
- 动态天象：
  - 白天（06:00–18:00）太阳沿抛物线从画面左侧升到右侧，颜色随高度由浅金渐变到落日橙；
  - 夜间（18:00–06:00）月亮沿反向弧线移动；
  - 月相按真实朔望月计算：朔望月 `29.530588853` 天，基准新月 `2000-01-06 18:14 UTC`，用像素矩形逐行绘制亮面。
- 环境层：像素云缓慢漂移、14 颗星闪烁、6 只萤火漂移、偶发流星与呼吸光晕；窄屏隐藏部分云层，`prefers-reduced-motion` 下整体不播放。

### 5.3 倾诉（`/chat`）

- 独立倾诉页，保留完整安全链路：危机词检测、风险分级、紧急会话锁定、双确认、真人安全交接。
- 空会话展示欢迎语、开场短语和**可选** PHQ-9 筛查卡；筛查默认关闭，由后端开关控制。
- 对话气泡、快捷短语、输入框、发送按钮均为像素点缀样式；聊天页**禁止玻璃拟态**（无 `backdrop-filter`）。
- 任意处打字可直接聚焦输入框；桌面端自动聚焦并在回复后归还焦点；移动端不自动弹出键盘。
- 结束倾诉需二次确认；结束后生成小结，可查看、删除；紧急会话禁止生成普通小结。
- 学生 Agent 栏默认折叠，只能手动展开；折叠态显示最新步骤，不暴露模型思维链。

### 5.4 回顾（`/trend`）与我的（`/profile`）

- 回顾页：情绪轨迹、30 天报告、情绪日历、自评卡与图表；桌面端双栏，移动端单栏。
- 我的页：宠物亲密度、统计、设置、更多空间入口；`petCompanion.js` 只读房间写入的宠物状态，不反向修改。
- 两页均使用 `.game-page` 昼夜皮肤与像素点缀，标题使用像素字体，正文保持系统字体。

### 5.5 树洞与疗愈

- `TreeHoleView.vue`：心情 chips、输入卡、漂流露珠卡与发送按钮；正文不换像素字体，避免长文本可读性下降。
- `HealingView.vue`：疗愈卡片与按钮统一 2px 边框、6px 圆角、硬投影；保留原有内容与交互。

### 5.6 心岛与休闲玩法

- 心岛容器 `StudentIslandWorkspace.vue`：地图、地点导航、活动面板、Agent 侧栏、移动端控制。
- 六个子玩法：钓鱼、种植、呼吸、潮汐沙滩、幸福交换、宠物家园。
- 本轮只像素化 HTML chrome（头部、按钮、面板、表单），**不改** canvas / 像素画内部与布局尺寸。
- 危机状态下，宠物倾诉与普通玩法会被暂停，优先展示 12356、110、120 安全行动层。

### 5.7 标准筛查（PHQ-9，默认关闭）

- 入口：倾诉页空会话的可选卡片，约 2 分钟，9 题、0–3 分、总分 0–27。
- 计分与分级完全在本地完成：

| 总分 | 分级 |
|---|---|
| 0–4 | 无明显 |
| 5–9 | 轻度 |
| 10–14 | 中度 |
| 15–19 | 中重度 |
| 20–27 | 重度 |

- 风险分流：第 9 题阳性 → `urgent`；总分 ≥15 → `professional`；≥10 → `watch`；其余 `routine`。
- 第 9 题安全标记只在激活时把风险提到 `urgent`；已确认联系可信成年人的专业级风险降为 `watch`。
- 结果保留 90 天，可随时删除；超过 30 天的结果不再参与当前风险判断。
- 教师端只看分级、总分、填写时间与第 9 题安全标记，**看不到单题答案**；结果不发送外部模型。
- 默认 `STUDENT_SCREENING_ENABLED=false`；开启前需学校心理老师/合规负责人复核中文措辞与教师可见口径。

### 5.8 无障碍与响应式

- 弹层使用 `activateDialog()`：Esc 关闭、Tab 在弹层内循环、关闭后焦点回到触发元素；输入法合成期间不响应 Esc/Tab。
- 焦点样式：金色虚线 `3px dashed` + `outline-offset: 4px`。
- `prefers-reduced-motion: reduce` 下关闭漂移、闪烁、粒子与页面过渡。
- 移动端安全区适配；窄屏隐藏部分装饰云层；长文本、聊天气泡与昵称保持系统字体，不裁切。

## 6. 视觉系统

### 6.1 像素点缀（学生端）

| 元素 | 规范 |
|---|---|
| 卡片 | `border: 2px solid var(--px-line)`；`border-radius: 6px`；`box-shadow: 4px 4px 0 var(--px-shadow)` |
| 按钮/输入/标签页 | 2px 边框；4px 圆角；`3px 3px 0` 硬投影 |
| 悬停/按下 | 悬停位移 `-1px,-1px` 并加 1px 投影；按下位移 `2px,2px` 并减至 1px |
| 标题/kicker | 中文像素字体；页级标题 24–48px；kicker 12px + 金色方块 |
| 消息气泡 | 2px 边框 + 4px 圆角，不加硬投影（避免长列表噪点） |
| 焦点 | `outline: 3px dashed var(--px-gold); outline-offset: 4px` |
| 禁止 | 不给正文/聊天记录/昵称套像素字体；聊天页不新增 `backdrop-filter`；不新增 `!important` 冲突 |

### 6.2 主题 token

- 学生子页在 `.game-page` 内重映射 `--m-radius-lg: 6px`、`--m-radius-md: 4px`、`--m-radius-sm: 3px`，登录页共用 token 不受影响。
- 三档主题各有一组 `--px-line`、`--px-gold`、`--px-shadow`：白天棕色线/暖金，傍晚与夜晚浅金线/深色硬投影。
- 首页使用 `--lobby-*` 全套 token（底色、卡片、金色、网格线、光晕、CTA、像素线/投影、环境色），与子页 token 解耦。

### 6.3 字体

| 字体 | 用途 | 文件 | 大小 |
|---|---|---|---|
| `Fusion Pixel Lobby` | 首页标题、时间、版本、kicker | `fusion-pixel-sc-lobby.woff2` | 约 3.5 KB |
| `Fusion Pixel Student` | 学生子页标题、按钮、标签 | `fusion-pixel-sc-student.woff2` | 约 49.8 KB |

- 源字体：`@fontsource/fusion-pixel-12px-proportional-sc` 5.3.0，SIL Open Font License 1.1；许可文本随字体存放。
- 子集由 `frontend/scripts/build_student_font_subset.py` 扫描学生端模板生成，只保留实际用到的中文与可见 ASCII；缺字时按字体栈回退系统字体。
- 字体使用 `font-display: swap`，不阻塞首屏。

### 6.4 大厅场景生成

- `frontend/scripts/gen_lobby_scenes.py` 用纯 Python 生成三张 SVG，不依赖外部图片。
- 画面拆成天空、远山、岛屿、树、房屋、灯笼、水面等图层；颜色随昼夜切换。
- 日月由首页动态天象层绘制，SVG 中不出现太阳/月亮色值，避免与真实时间冲突。
- 生成命令：`npm run scenes:lobby`。

## 7. 后端与智能体

### 7.1 小满对话引擎（DeepSeek）

- 默认 `STUDENT_COMPANION_ENGINE=deepseek`，通过 DeepSeek 的 OpenAI 兼容 `chat/completions` 接口调用 `deepseek-chat`。
- 小满提示词定义“先接住、少提问、像发消息、不问诊”的节奏，并维护 9 个话题状态；界面不展示分数、量表名、诊断词。
- 对话调用参数：温度 0.85、最多 1600 tokens、超时 45 秒；小结调用温度 0.6、最多 1200 tokens。
- 请求失败、返回空内容或结构异常时显式抛错，由上层降级为本地安全回应；不出现空白气泡或死路。
- 旧分支：`STUDENT_COMPANION_ENGINE=legacy_xunfei` 回到讯飞策略协作，需要另行配置讯飞能力。

### 7.2 倾诉后小结

- DeepSeek 只依据学生自己的原话撰写，引用必须能在原话中逐字找到。
- 风险等级、情绪标签、边界与结构字段仍由本地确定性流程裁决。
- 出现分数、量表名、诊断词、内部标记或引用无法逐字匹配时，整份回退本地模板。
- 小结可删除；紧急会话禁止生成普通小结。

### 7.3 多 Agent 支持流程

- 顺序：确定性安全分流 → 任务理解 → 规划 → 支持回应编排 → 交付核验 → 倾诉后小结。
- 任务契约包含目标、约束、验收条件、实际工具与下一责任人；危机路径单独生成“真人安全支持接力”交付物。
- 教师端只接收去标识化任务摘要与核验状态，不新增聊天原文副本；Agent 默认折叠，不展示思维链。

### 7.4 教师端与守护者端

- 教师端：班级概览、学生列表、预警、访问申请与审批、个案上下文、授权工作成果、审签报告与 PDF、可选教师任务规划。
- 守护者端：合成数据确认、去标识化校验、个案接待、证据、回访与 PDF；失败时降级为审核模板。
- 教师/守护者页面不使用学生端 `--px-*` 像素 token，保持工作台风格。

## 8. 数据、安全与隐私

### 8.1 身份与授权

- 学生身份以后端 HttpOnly 会话 Cookie 为准；前端不依赖可伪造的 `user_id`。
- 教师查看学生原文或授权成果需要有效的访问申请/审批；管理员教师按既有规则直达。
- 学生外部 AI 授权：
  - `teacher_authorized`：逐学生教师登记，授权版本 `teacher-ai-authorization-v3`；
  - `platform_direct`：运营方在站点层完成治理确认，版本 `platform-direct-transcript-v3`；
  - 旧版本授权自动失效，需要重新确认。
- 生产环境强制 `DEMO_MODE=false` 且 `COOKIE_SECURE=true`。

### 8.2 危机与安全交接

- 本地确定性规则优先于模型：危机词、safeguarding、紧急分流先执行。
- 紧急会话停止普通生成，交付可信成年人、12356 心理支持热线；迫切危险时提供 110/120。
- 紧急状态不可被普通对话或筛查绕过；结束小结、PDF 等普通产物会被阻断。
- 学生确认联系可信成年人后，筛查结果保留，专业级风险降为 `watch`；`urgent` 安全标记不可绕过。

### 8.3 数据留存与审计

- 倾诉会话与小结按既有 30 天留存与本人删除规则处理。
- 筛查结果保留 90 天，可随时删除；超过 30 天不再参与当前风险判断。
- 敏感访问、外部模型传输、筛查提交/确认/删除等写审计记录。
- 外部模型只接收完成当前任务所需的最小内容；姓名、学校、联系方式、精确地址和原始录音不发送。

### 8.4 已知隐私注意点

- 首页天气使用 Open-Meteo，浏览器定位坐标会发送到该外部服务；拒绝定位时使用默认城市坐标。
- DeepSeek Key 只放在后端 `.env`，不下发浏览器；不要把填好 Key 的 `.env` 提交或转发。
- `PLATFORM_STUDENT_AI_GOVERNANCE_ACK=true` 表示运营方接受“对话原文发送给外部模型，用于回应和小结”，只应在本机演示时打开。

## 11. 已知限制与待办

1. **版本字符串未升级**：内容已超过 `5.1.0-alpha.41`，正式发版前应统一 `package.json`、`config.py`、`CHANGELOG.md` 与构建徽标。
2. **PHQ-9 需要专业复核**：中文措辞、分级解释与教师可见口径必须由学校心理老师/合规负责人确认后才可开启；当前默认关闭。
3. **DeepSeek 依赖外部服务**：Key 额度、延迟与可用性由平台账户决定；没有 Key 时为降级体验。
4. **可选 Agent 依赖未安装**：`langgraph` 缺失导致 5 个后端测试模块无法导入；安装 `requirements-agent.txt` 后可解除。
5. **既有 PDF 断言失败**：`test_guardian_workflow` 的 PDF 体积断言仍为 20000 字节，当前生成 8178 字节；需确认是字体/压缩变化还是内容缺失，再更新断言或修复。
6. **前端 2 项部署测试失败**：仓库不含 Windows 专用 `deploy-frontend.ps1`，与产品功能无关。
7. **天气与定位**：Open-Meteo 不可用时显示 `--`；定位被拒绝时使用默认坐标，不保证与用户所在地一致。
8. **月相为近似算法**：按平均朔望月与固定基准计算，适合氛围展示，不用于天文计算。
9. **大 chunk 警告**：Phaser 与主包体积偏大，后续可继续拆分；当前按需加载已避免进入首屏关键路径。
