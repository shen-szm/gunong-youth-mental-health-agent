## 恢复后的收口结果

- 模型不再返回任何学生可见自由文本，只能从严格枚举中选择情绪、支持需要、回应风格和追问焦点；后端审核话术库负责最终表达。
- 任意 `reply`、`reply_text`、危险建议、用药内容或虚构事件字段都会因 `extra="forbid"` 被整份拒绝并安全降级。
- 长对话回复会在审核过的开场与追问组合中避开最近相似内容；运行记录如实标记为 `xunfei-response-strategy-selector`。
- Agent 已默认折叠并只能手动展开，折叠态显示最新状态；中等桌面宽度避让、动态可访问名称、实时提示、Esc 和焦点返回均已补齐。
- 当前已通过后端 103 项、前端 95 项、学生端完整浏览器 E2E 及生产构建；心理安全、后端权限隐私、前端体验三方复核均已清零 P0/P1。

## 本轮已完成

- 学生身份改为以后端 HttpOnly 会话为准；前端聊天接口不再依赖残留的 `user_id`，伪造跨用户 ID 仍会被拒绝。
- 学生聊天使用讯飞严格枚举策略选择，最终回复来自后端审核话术库，并保留确定性危机分流、诊断禁区和失败降级。
- Agent 与聊天工作区解耦：进入倾诉空间、发送消息时不自动展开，只能由学生手动点击打开；折叠态保留最新工作状态。
- Agent 面板已重构为较轻量的中文协作时间线，技术字段和数据来源收进二级详情。
- 版本号和变更日志已暂时更新到 `5.1.0-alpha.28`。
- 在最近一次安全审查前，后端 101 项测试、前端 95 项测试和前端构建均通过。

## 暂停前正在处理

三个独立审查 Agent 已完成首轮检查，发现以下 P1，部分修复已写入工作区，但尚未完成测试：

1. 隐私：外部模型不应收到任何聊天原文。`backend/api/chat.py` 已改为仅发送本地提取的情绪、支持主题、功能影响、持续性等去标识化结构特征。
2. 输出安全：已扩充诊断、药物、自伤方法、隐瞒求助等拦截，并增加对模型虚构人物、事件、时间和话题的接地校验。
3. 回复重复：已加入最近四条助手回复的相似度检测，不再只比较完全相同的字符串。
4. 模型来源真实性：模型缺少合法 `reply` 字段时应安全降级，不能标记为讯飞自然回复；Schema 已将 `reply` 改为必填。
5. 前端中等桌面宽度：900–1199px 展开 Agent 时可能遮挡聊天面板，尚需恢复聊天面板让位规则。
6. 无障碍：折叠按钮的可访问名称尚需包含最新状态，并增加折叠状态的 `aria-live` 提示。
7. 文案：学生端和 Agent 数据来源说明仍写着“去标识化近期对话”，应改成“仅发送本地提取的去标识化结构线索，聊天原文不外发”。
